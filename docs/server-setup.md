# Параметры для развёртывания на учебной ВМ

- Образ GHCR: `ghcr.io/chuviss/devops-ci-app`. Публичное чтение без токена проверено через Docker pull.
- Проверенный исходный тег для воспроизводимого запуска: `e62cfe4662c8727674c90ed6b37a4e93acfe4170`.
- Digest этой версии: `sha256:37eb3abdbf22382136ade2786bf7a0b523d38c9417c1eb0985c668032d1633b0`.
- Платформа образа: `linux/amd64`. На arm64 нужна поддержка эмуляции.
- Порт Gunicorn в контейнере: `5000/tcp`. Для локального доступа на ВМ: `127.0.0.1:5001:5000`.
- Контрольный запрос: `GET http://127.0.0.1:5001/health` должен вернуть HTTP 200 и `{"status":"ok"}`.

Адрес ВМ, имя пользователя и параметры SSH берутся из Ansible inventory целевого стенда. При обновлении фиксируйте полный проверенный SHA-тег или digest. CI уже собирает и проверяет образ, поэтому задача развёртывания загружает его из GHCR.
